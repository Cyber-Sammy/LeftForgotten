# Left Forgotten - 1.1.1 Release

### ***BUG FIXES/TECHNICAL CHANGES***
- Removed the "TP to spawn" feature when "dying" in `left_forgotten:alpha_minecraft` and replaced it with a different mechanic
  - Now if the damage amount is lethal, player will always end up at half a heart instead of dying or getting teleported to their spawn point. <sub>Unless the damage is higher than 512</sub>
- Fixed remodels of the Furnace and Crafting Table in `left_forgotten:alpha_minecraft`
- Added in a bunch of wood and stone related item tags that were previously missing

### ***DEV STUFF***
- Adapted DatagenDataUtil class to replicate one in MysticLib that still has yet to release
- Shortened IF statements for mixin cancellers of C2ME's PerlinNoiseOverwrite mixin class
