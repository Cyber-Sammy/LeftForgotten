# Left Forgotten - 1.1 Release
<small>***Remember that any mentions of blocks that are in vanilla Minecraft in this changelog, are not vanilla (unless specified) and are Alpha MC variations of them._***</small>

### ***BLOCKS***
- Added Red and Brown Mushroom
- Added Cactus
- Added Iron, Gold and Diamond Block(s)
  - Craftable only with use of Polymorph due to being the same recipe as vanilla's

### ***WORLDGEN***
- The Red Flower is now more common, somewhat the same as the Yellow Flower
- Mushrooms now naturally generate in `left_forgotten:alpha_minecraft` in patches
- Cacti now naturally generate in `left_forgotten:alpha_minecraft` in patches

### ***GAMEPLAY***
- Expanded on supported foods in AlphaFoodSystem
  - Now supports basically every Vanilla food item
  - All items keep their properties like applying effects, resulting items after consumption and other
- Added the pre-1.9 boat
- Emitted light (from blocks) now appears blocky (No AO) in `left_forgotten:alpha_minecraft`
- Music played in `left_forgotten:alpha_minecraft` is only C418's from about the era of Minecraft Alpha
- Vanilla Crafting Table, Furnace and Chest appear like ones from a1.1.2_01 only in `left_forgotten:alpha_minecraft`

### ***BUG FIXES/TECHNICAL CHANGES***
- Added missing Furnace and Crafting Table recipes
- Added missing Iron Door recipe
- Reordered the items in the creative tab
- Fixed air bubbles appearing underwater in creative on Forge
- Fixed some recipes that should be in Left Forgotten's data being in Minecraft's data directory
  - Resolved issue: unspecified datagen writer location
- Feature Void now disappears after doing its job as it should
  - Resolved issue: changed tick method override to animateTick in block class
- Clay now spawns naturally
  - Resolved issue: missing configured and placed clay ore feature
- Redstone Ore spawns naturally
  - Resolved issue: incorrect tag match in configured feature
- Wood-6-Sided now has log XYZ rotation
  - Resolved issue: unspecified rotation type in datagen
- Fixed block properties and block tags
- Corrected Version Overlay texts

### ***DEV STUFF***
- Removed debug logger from CancelPerlinNoiseOverwrite class
- Feature Void no longer appears in the Left Forgotten creative tab
- Removed `left_forgotten:oregen_replaceable` tag
- Configured ore features now use `minecraft:stone_ore_replaceables` tag match
  - Added `left_forgotten:stone` to `minecraft:stone_ore_replaceables` tag
